# 도전 (도움전화) — 어르신 전화 도우미

[한국어] · [English](./README.md)

**도전(도움전화)** 은 어르신을 위한 접근성 우선(accessibility-first) 전화 도우미
웹 앱입니다. 큰 얼굴+이름 카드를 눌러 가족에게 전화하고, 휴대폰 기능을 한 단계씩
배우며, 긴급 상황에서 보호자에게 SOS를 보낼 수 있습니다. 모든 것이 크고, 대비가
뚜렷하며, 소리로 읽어줍니다.

이 앱의 핵심은 **접근성**입니다. 큰 글씨(약 200%까지 확대), 48px 이상의 큰 터치
영역, 두 테마 모두에서 강한 대비, ARIA 라벨, 키보드 초점, 그리고 **실제 음성 안내**.

## 라이브 데모

**https://clsoftlab-lang.github.io/senior-phone-helper/**

## 주요 기능

- **큰 즐겨찾기 연락처** — 색깔 있는 얼굴 그림(사진 자리) + 이름, 누르면 전화.
- **자주 쓰는 기능 큰 버튼** — 전화, 문자, 카카오톡 열기, 카메라, 복약 알림, 긴급.
- **사용법 가이드(튜토리얼)** — 큰 그림·큰 글씨로 한 단계씩: "문자 보내는 법",
  "사진 찍는 법", "와이파이 연결하는 법", "카카오톡 여는 법", "소리 크기 조절".
  음성으로 읽어주고, 이전/다음으로 천천히.
- **긴급 SOS** — 커다란 빨간 단추 하나로 보호자에게 위치 + 도움 요청을 모의 전송
  (허용 시 실제 위치 정보 사용).
- **실제 음성 안내** — Web Speech API(`speechSynthesis`)로 단추·안내를 읽어줍니다.
  한국어 음성 우선, 미지원 기기에서는 자동으로 건너뜁니다.
- **글자 크기 조절** — 보통부터 아주 크게(약 200%)까지 5단계, 저장됨.
- **고대비 모드** — 검정 바탕에 밝은 글씨, 저장됨.
- **보호자 설정 화면** — 큰 UI로 SOS 보호자 등록, 연락처 추가·삭제.
- **추가 기능** — 오늘 날짜·요일 크게 표시, 복약 알림 켜기/끄기, 잘못 눌러도
  되돌아가는 항상 있는 큰 '뒤로' 단추.

## 🤖 AI 기능 (API 연동)

**AI 도우미** 탭에 어르신을 위한 AI 기능 3가지가 있습니다. 모두 큰 글씨로 보여주고
음성(TTS)으로 읽어드립니다.

1. **AI 쉬운 도우미 챗봇** — "어떻게 하나요?" 같은 휴대폰 질문에 쉬운 말로 답해줍니다.
2. **말로 문자 초안 만들기** — 짧게 말하거나 적은 뜻을 정중한 문자 초안으로 만들어 줍니다.
3. **오늘 안내** — 오늘 날짜와 알림을 큰 글씨로 간단히 알려줍니다.

**데모 = 목업(기본값).** `ai/config.js`의 `AI_ENDPOINT`가 비어 있으면 모든 기능이
인터넷 없이 동작합니다. 앱의 연락처·튜토리얼 데이터를 그대로 활용하는 결정적
한국어 MockProvider가 답을 만들며, 키도 네트워크도 필요 없습니다.

**실제 Claude 연동:** [`server/`](./server/)의 백엔드 프록시를 실행하세요. 키를
서버에만 두고 답을 스트리밍합니다.

```bash
cd server
cp .env.example .env          # .env 에 실제 키를 붙여넣기
npm install && npm start      # http://localhost:8787
```

그 다음 `ai/config.js`에서 주소를 설정합니다.

```js
export const AI_ENDPOINT = "http://localhost:8787/api/ai";
```

프록시는 서버의 `ANTHROPIC_API_KEY`로 Claude(비용 우선 기본 모델
**`claude-haiku-4-5`**, `AI_MODEL`로 변경 가능)를 호출합니다.

> **🔒 보안: 키는 오직 서버에만.** API 키는 서버의 `ANTHROPIC_API_KEY`에서만
> 읽으며, 브라우저·`ai/config.js`·저장소에는 **절대** 넣지 않습니다. `ai/config.js`에는
> 주소(URL)만 들어가고, `.env`는 gitignore로 제외됩니다.

## ⚙️ 고도화 — 무인·저비용 실 AI 연동

실제 Claude를 **무인**·**저비용**으로 연결했습니다. 문제가 생겨도 항상 오프라인
목업으로 되돌아가므로 앱이 절대 멈추지 않습니다.

- **비용 모델.** 기본 **`claude-haiku-4-5`** (약 **$1 / $5 per MTok** 입력/출력).
  작업별 고정 시스템 프롬프트에 **프롬프트 캐싱**을 적용해 반복 호출이 더 저렴하고,
  출력은 작업별로 (~500–700 토큰) 제한합니다. **월 토큰 한도**(`AI_MONTHLY_TOKEN_CAP`,
  기본 200만)와 IP별 요청 제한으로 비용을 묶어 둡니다. 대략 **1,000회당 약 $2–3**
  수준입니다. 품질을 높이려면 `AI_MODEL`을 `claude-sonnet-5` / `claude-opus-5`로
  올리면 됩니다(비용도 함께 증가).
- **무인 무료 호스팅.** [Cloudflare Workers](./server/) 변형
  (`server/worker.js` + `wrangler.toml`)은 무료 요금제에서 한 번의 명령으로
  배포됩니다 — 관리할 서버가 없습니다. `wrangler secret put ANTHROPIC_API_KEY`,
  `wrangler deploy`.
- **절대 멈추지 않음.** 네트워크 오류, 비정상 응답, `429 {fallback:true}`(요청 제한
  ·예산 초과) 시 브라우저가 조용히 오프라인 목업을 사용합니다.
- **무인 "오늘 안내".** 첫 화면(홈)을 열면 오늘 안내(날짜, 복약·알림, 날씨와 무관한
  건강 팁)를 `askAI`로 자동 생성해 음성(TTS)으로 읽어드립니다 — 오프라인 목업에서도
  동작합니다.

> **🔒 API 키는 오직 서버에만 — 브라우저나 저장소에는 절대 넣지 않습니다.** 키는
> `ANTHROPIC_API_KEY`(Node `.env`, gitignore) 또는 Cloudflare Worker 시크릿에만
> 존재하며, `ai/config.js`에는 주소(URL)만 들어갑니다.

## 로컬 실행

빌드 과정 없음. 정적 서버면 됩니다.

```bash

```

## 데모 모드 한계 (중요)

> **이 앱은 데모입니다. 실제 동작으로 오해하지 마세요:**
> - **연락처는 가상입니다.** 실제 사람·전화번호·개인정보(PII) 없음.
> - **localStorage는 진짜 데이터베이스가 아닙니다.** 설정·연락처는 이 브라우저에만
>   저장되고 언제든 지워질 수 있습니다.
> - **`tel:` / `sms:` 는 기기에 따라 다릅니다.** 실제 폰에서는 전화·문자가 열리고,
>   PC에서는 확인 창만 보여줍니다.
> - **SOS는 모의(시뮬레이션)입니다.** 실제로 어디에도 전송되지 않습니다. 진짜
>   위급하면 **119**에 전화하세요.
> - **실제 계정·로그인·서버 없음.**
> - 실제 상용 버전에서는 백엔드, 실제 SOS 전송, 보호자 동기화, 검증된 연락처가
>   추가됩니다.

## 접근성 설명

- 최소 20px 기본 글씨, 약 200%까지 확대(`--font-scale`).
- 모든 조작 요소 48px 이상(기본 60px) 터치 영역.
- 기본/고대비 두 테마 모두 WCAG를 고려한 대비.
- 내비게이션·연락처·기능 버튼에 ARIA 라벨, 상태 안내용 `aria-live` 영역.
- 뚜렷한 키보드 초점(4px 외곽선), 본문 건너뛰기 링크, 화면 이동 시 제목으로 초점 이동.
- `prefers-reduced-motion` 존중(SOS 깜빡임·누름 애니메이션 비활성화).

## 기술

- 정적 SPA: `index.html` + `styles.css` + ES 모듈 자바스크립트. 빌드 없음, 의존성
  없음, 상대 경로만 사용.
- 모듈: `js/storage.js`(안전한 localStorage), `js/speech.js`(Web Speech API),
  `js/settings.js`(글씨/대비/음성), `js/contacts.js`(데모 연락처), `js/icons.js`(인라인 SVG 아이콘·아바타).
- 데이터: `data/contacts.json`, `data/tutorials.json`, `data/functions.json`(모두 가상 데모 데이터).
- CI: GitHub Actions가 `node check.mjs` 실행.
